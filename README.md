# Project Eternal Grind

Idle-/Auto-Battler-Grinding-RPG für das iPhone (Safari, Hochformat). Keine Installation, kein Build.

## Starten

Im Projektordner:

```
python3 -m http.server 8080
```

Dann im Browser `http://localhost:8080` öffnen.
Auf dem iPhone (gleiches WLAN): `http://<IP-des-Computers>:8080`.

## Stand

Phase 2: 5 Dungeons mit Bossen, alle Seltenheiten, Skills, Item-Vergleich, AUTO EQUIP, Statistiken, Achievements, Export/Import. Alle Balancing-Werte stehen in `src/data/config.js`.
